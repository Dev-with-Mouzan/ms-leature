NOORI NASTALEEQ — how to activate it
=====================================

This folder is empty on purpose. The site already looks for a Noori
Nastaleeq font file here and uses it automatically as soon as you add one.

Supported file names (either one is enough):

    Jameel-Noori-Nastaleeq.woff2   (preferred — smallest)
    Jameel-Noori-Nastaleeq.ttf
    Noori-Nastaleeq.woff2
    Noori-Nastaleeq.ttf

Where to get it
---------------
"Jameel Noori Nastaleeq" is a free Urdu typeface (by Jameel Noori / InPage
lineage) distributed by many Urdu font sites. It is free to use, but it is
NOT open-licensed — if this website is published publicly, keep the font
file out of public repositories if its licence requires that, or use the
bundled open-licensed Noto Nastaliq Urdu instead (which is used until a
Noori file is present).

Until a file exists here
------------------------
Every Urdu text on the site falls back to Noto Nastaliq Urdu (loaded from
Google Fonts at build time by next/font). Nothing breaks; the design and
line-heights are tuned for Nastaliq metrics, so both fonts look correct.
